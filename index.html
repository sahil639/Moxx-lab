Moxx Lab

Mockup animations. Each one is a single self-contained page with its own control panel, built to be tuned in the browser and screen-recorded.

Animations

  • Terminal Type 01

    Portrait terminal text that types itself in, a scramble of glyphs decoding just ahead of the write head, over scanlines and flicker. Drop in any font file to see it set in that face.
  • Dither Lab 02

    Drop an image or a video and it is dithered live on the GPU — Bayer, noise or halftone, down to a few tones and a three-colour palette, with a lens that sharpens wherever the cursor rests.
Self-contained pages — no build step, no dependencies, no network requests.
