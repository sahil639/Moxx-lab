• Terminal Type 01

    Portrait terminal text that types itself in, a scramble of glyphs decoding just ahead of the write head, over scanlines and flicker. Drop in any font file to see it set in that face.
  • Dither Lab 02

    Drop an image or a video and it is dithered live on the GPU — Bayer, noise or halftone, down to a few tones and a three-colour palette, with a lens that sharpens wherever the cursor rests.
  • Line Relief 03

    A field of parallel lines pushed sideways by an image's brightness, so the picture exists only as deformation — bunching into dense bands where it steepens, thinning into dots where it spreads.
  • Glyph Matrix 04

    A grid of small marks that reads a picture or a video and redraws it in its own alphabet — rings, bars, crosses, characters — one glyph and colour per tonal band, with a wave running through the lattice.
  • Prism Core 05

    A soft, rounded block that glows from the inside — orbs, translucent layers and drifting motes moving through it. Turn it by hand, change its shape, view and arrangement, and build the gradient from as many colours as you like.
